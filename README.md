# 로트워치 (LotWatch)

배치(lot)별 품질검사 결과 추세 대시보드 시제품
2026 NI2.0 AID 해커톤 8팀 **혼돈즈** (순천제일대학교 산업기술화공과) · 기업 연계 과제: ㈜포스포

> 품질관리(QC) 담당자가 배치별 검사 결과를 엑셀에 쌓아 두는 상황에서 겪는 '규격 이탈·추세 이상을 늦게 발견하는 불편'을 '배치별 추세 차트와 이상 배치 자동 경고'로 줄이는 웹앱

## 핵심 기능
1. **배치별 추세 차트**: 검사 항목별 측정값을 생산 순서대로 보여 주고, 규격 상·하한선, 평균선, ±3σ 선을 함께 표시
2. **이상 배치 자동 경고**: 🔴 규격 이탈, 🟠 같은 방향 6배치 연속 상승·하강, 🟠 평균 ±3σ 밖

## 사용 방법
- `index.html` 한 파일로 동작합니다. 빌드, 서버, 로그인이 필요 없습니다.
- 데이터는 사용하는 브라우저에만 저장되고 서버로 보내지 않습니다.
- CSV 열 구성: `lot_no, prod_date, product`, 그 뒤에 검사 항목 열(숫자)

## 데이터 안내
앱에 들어 있는 값은 모두 **샘플 데이터**(실습용 예시)이며 실제 ㈜포스포 데이터가 아닙니다. 검사 항목과 규격도 가설입니다. 조사 근거와 출처는 [project-plan.md](project-plan.md)에 있습니다.
